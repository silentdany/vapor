# Vapor

Vitrine des jeux décompilés qui tournent dans le navigateur. Les capsules sont des scènes originales dans le rendu de la machine (N64 bas-poly, Game Boy, DOS, VGA), pas des photos et pas les jaquettes. Un lieu ou un objet, pas les personnages. Vapor n'héberge aucune donnée de jeu.

Domaine prévu : [vapor.accura.dev](https://vapor.accura.dev)

## Mettre en ligne

Importer ce dépôt sur Vercel, puis ajouter le domaine `vapor.accura.dev`.
