# Vapor

Vitrine des jeux décompilés qui tournent dans le navigateur. Les capsules sont des scènes originales, pas les jaquettes : un lieu ou un objet, pas les personnages. Vapor n'héberge aucune donnée de jeu.

Domaine prévu : [vapor.accura.dev](https://vapor.accura.dev)

## Mettre en ligne

Importer ce dépôt sur Vercel, puis ajouter le domaine `vapor.accura.dev`.
