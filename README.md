# Vapor

Vitrine des jeux décompilés qui tournent dans le navigateur. Les capsules sont des scènes originales, pas les jaquettes. Trois exceptions, de vraies captures sous licence libre : OpenTTD (GPL-2.0, Theki), Freedoom (BSD, Hugo Locurcio), OpenTyrian (CC BY 3.0, développeurs OpenTyrian). Vapor n'héberge aucune donnée de jeu.

Domaine prévu : [vapor.accura.dev](https://vapor.accura.dev)

## Mettre en ligne

Importer ce dépôt sur Vercel, puis ajouter le domaine `vapor.accura.dev`.
