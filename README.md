# Vapor

Vitrine des jeux décompilés qui tournent dans le navigateur. Les capsules sont des scènes dans une brume, pas les jaquettes. OpenTTD, Freedoom et OpenTyrian partent de captures sous licence libre, puis la même brume : OpenTTD (GPL-2.0, Theki), Freedoom (BSD, Hugo Locurcio), OpenTyrian (CC BY 3.0, développeurs OpenTyrian). Vapor n'héberge aucune donnée de jeu.

Domaine prévu : [vapor.accura.dev](https://vapor.accura.dev)

## Mettre en ligne

Importer ce dépôt sur Vercel, puis ajouter le domaine `vapor.accura.dev`.
